# CodeTrack — Student (1 page)

## Lab PC (recommended)

1. Open **CodeTrack Student** (Quickball on the desktop / Start Menu).
2. Enter the **session code** from the board or QR.
3. Search your **name** or **roll number** (2+ characters).
4. Enter your **4-digit PIN** (or create one the first time).
5. For each task, tap: **Not started** / **Working** / **Done** / **Need help**.
6. Collapse the ball and keep coding — status stays connected.

**Do not** also open the browser join page (`/join`) on the same PC.

## Phone (no Windows install)

1. Scan the QR or open the link (ends with `/open?code=…` or `/join?code=…`).
2. On Android/iPhone: use the browser, or **Add to Home Screen** for the CodeTrack PWA.
3. Same steps: find yourself → PIN → update status.

## Tips

- Stay on Wi‑Fi. If you reconnect, the app restores your session while the lab is still active.
- If you see “Signed in elsewhere”, only one device can be live — use either phone or lab PC, not both.
- Wrong PIN too many times locks you out briefly — wait and try again.
