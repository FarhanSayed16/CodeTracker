# CodeTrack — Professor (1 page)

## Before class

1. Open the **web dashboard** in a browser.
2. Create / select the class, import roster if needed.
3. Start an **ACTIVE** session and note the code (or show QR).

## During class (while coding)

1. Open **CodeTrack Lab Monitor** (Quickball).
2. Sign in with your professor account.
3. Attach the ACTIVE session (or **Attach latest**).
4. Watch **Joined / Done / Working / Issues** on the ball.
5. Use **Mute alerts** if the full dashboard grid is already open (avoid double noise).
6. **Open dashboard** from the ball when you need the full grid or to add tasks.

## Ending

- Prefer **End session** from the dashboard or Lab Monitor when the lab is over.
- Create sessions and rosters only on the **dashboard** — not inside the ball.

## Tips

- One Lab Monitor + optional dashboard is enough; students should use Student Quickball or phone `/join`.
- If counts look stale, check the green **Live** indicator; Refresh / re-attach the session.
